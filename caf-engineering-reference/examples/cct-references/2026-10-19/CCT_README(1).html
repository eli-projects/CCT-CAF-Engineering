Controller Configuration Tool (CCT)

CCT Overview

You can use CCT to configure, simulate, commission, and transfer application files to various controllers, input/output modules, and expansion modules.

For details, refer to the Controller Tool Help (LIT-12011147) that is accessible on the Johnson Controls® Knowledge Exchange website.

New or Upgrade Installation of CCT

For instructions on installing or upgrading CCT, refer to the Controller Tool Installation Instructions (LIT-12011529).

Licensing the Software

You must license Metasys software before you can use it. We recommend that you do so immediately after installation. Run the Software Manager and refer to the Software Manager Help (LIT-12012389) for information and instructions.

Problem Fixes and Software Patches

Patches for software releases are posted on the License Portal.
